# SWiSH — bag-on-scale loading animation

A seamlessly looping loader on a white page. A kraft bag falls straight down
into frame, lands on a silver scale with a small bounce, and the green digital
readout fills a fixed five-cell display:

```
.....  →  S....  →  SW...  →  SWi..  →  SWiS.  →  SWiSH
```

A progress ring under the scale tracks the weigh and closes into a green tick
once the readout completes.

No runtime dependencies. The loader is plain ES modules and CSS — Vite is here
for the dev server, the test harnesses and the static build, and nothing in
`loader/` imports it.

## Run it

```bash
npm install
npm start            # dev server
npm test             # headless assertions, Chromium, several viewports
npm run build        # static bundle into dist/
```

`npm test` needs Chromium once: `npm run test:install`.

## Using it in an app

See **[`loader/README.md`](loader/README.md)** for the API, the React binding,
the lifecycle contract and the accessibility behaviour. The motion itself is
specified in **[`SWISH_LOADING_ANIMATION_SPEC.md`](SWISH_LOADING_ANIMATION_SPEC.md)**.

## Deploying

Vercel picks this up with no configuration beyond
[`vercel.json`](vercel.json): `npm run build` → `dist/`. Import the repository
and deploy; there are no environment variables and no server side.

`npm run build` emits **only** `index.html`. The test harnesses under `tools/`
expose a timeline scrubber through the loader's `__debug` hook, so they are
kept out of the production bundle rather than left publicly reachable. To
check a built copy on a real device, `npm run build:harness` puts them back.

## Regenerating the artwork

The two raster layers are generated from the SVG exports in `assets/`, not
hand-edited:

```bash
pip install pillow segno
npm run assets
```

This crops the bag and the scale, paints out the scale's baked-in pilot dot,
applies the tamper seals and the feedback QR, and rewrites
`loader/swish-assets.js` with both layers inlined as data URIs. The QR is a
real symbol generated by `segno`, not drawn art.

## Layout

```
index.html       the deployed page: the loader, nothing else
loader/          the product — engine, CSS, generated assets, React binding
tools/           asset pipeline, test harnesses, headless runner
assets/          source SVG exports the pipeline reads
```

Development material that the build does not need — the abandoned first
attempt, reference video frames, screen recordings and the original composed
renders — is left on disk but kept out of the repository; see
[`.gitignore`](.gitignore).
